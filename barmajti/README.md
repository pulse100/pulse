# برمجتي — معرض هدايا إلكترونية

نموذج موقع لعرض تصاميم هدايا إلكترونية (تخرّج، عيد ميلاد، رسائل حب، مناسبات).
الزائر يتصفح ويختار تصميم، ويرسل الطلب جاهز على الواتساب. بدون تسجيل دخول وبدون دفع.

## الملفات
- `index.html` — الموقع كامل (الواجهة + لوحة التصميم)
- `logo.png` — الشعار
- روابط الأقسام: `?category=birthday` · `graduation` · `love` · `occasions` (أو `#birthday`)
- `designs.json` — (اختياري) التصاميم المنشورة للزوار. تنزّله من لوحة التصميم ← النشر

## لوحة التصميم
- افتح الرابط وأضف بنهايته `#admin` (أو اضغط على الشعار ٥ مرات بسرعة)
- رمز الدخول الافتراضي: `1234` — غيّره من تبويب "أرقام التواصل"
- من هناك: تضيف/تعدّل/تخفي التصاميم، ترفع خطوط (مثل الديواني)، وتضيف رقم الواتساب والهاتف

## النشر
التعديلات تنحفظ بمتصفحك. حتى يشوفها الزوار: لوحة التصميم ← النشر ← نزّل `designs.json` وارفعه جنب `index.html`.
