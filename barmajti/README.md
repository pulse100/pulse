# برمجتي — هدايا ودعوات إلكترونية

موقع يعرض تصاميم هدايا ودعوات إلكترونية (عيد ميلاد، تخرّج، رسائل حب، زفاف وخطوبة، مناسبات).
الزائر يتصفح ويفتح المعاينة، ويرسل الطلب جاهز على الواتساب. بدون تسجيل دخول وبدون دفع.

## شكل الهدية
كل هدية صفحة موبايل تنفتح بحركة (أبواب، ظرف، صندوق هدية)، وبيها:
الاسم، بطاقة الدعوة، الصورة، الموقع، صفحة التقويم، زر احفظ الموعد، عد تنازلي،
برنامج المناسبة، التفاصيل، كلمة الختام، وشريط سفلي (تواصل، موسيقى، تهنئة، الموقع، تأكيد الحضور).

## الروابط
- الأقسام: `?category=birthday` · `graduation` · `love` · `wedding` · `occasions` (أو `#birthday`)
- هدية واحدة لوحدها: `?gift=BR-201` (أو `#BR-201`). هذا الرابط اللي ترسله للزبون

## لوحة التصميم
- افتح الرابط وأضف بنهايته `#admin` (أو اضغط على الشعار ٥ مرات بسرعة)
- رمز الدخول الافتراضي: `1234`. غيّره من تبويب "أرقام التواصل"
- تضيف/تعدّل/تخفي التصاميم، ترفع خطوط (مثل الديواني)، وتضيف رقم الواتساب والهاتف
- لهدية زبون: انسخ تصميم، غيّر الاسم والتاريخ ورقم واتساب صاحب المناسبة، وخلّيه مخفي، ودزّ "رابط الهدية"

## النشر
التعديلات تنحفظ بمتصفحك. حتى يشوفها الزوار: لوحة التصميم ← النشر ← نزّل `designs.json` وارفعه جنب `index.html`.
